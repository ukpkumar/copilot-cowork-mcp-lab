# Session materials

This folder contains instructor-ready material for presenting the NASA Mars Rover MCP Connector and Plugin for Copilot Cowork from start to finish.

## Materials

| File | Purpose |
| --- | --- |
| `nasa-mars-rover-mcp-cowork-session.pptx` | Presentation deck for the session. |
| `generate-session-deck.mjs` | Reproducible deck-generation script. |
| [`../labs/nasa-mars-rover-mcp-cowork-end-to-end-lab.md`](../labs/nasa-mars-rover-mcp-cowork-end-to-end-lab.md) | Hands-on lab workbook. |

## Regenerate the deck

From the repository root:

```powershell
npm run deck:session
```
